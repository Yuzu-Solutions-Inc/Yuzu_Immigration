# Registre de destruction des dossiers (copie papier)

%PRODUCT_NAME% tient déjà un registre chiffré sous **Paramètres → Sécurité**. Utilisez cette feuille pour une copie papier ou hors ligne (audit du Collège).

|---|---|---|---|---|---|---|
|  |  |  |  |  | « Détruire le dossier » dans Yuzu |  |

Règle par défaut du produit : détruire seulement après **fermeture + 6 ans**, sauf autre règle de droit. Lorsque les fins sont atteintes, la Loi 25 du Québec vise la destruction ou l’anonymisation.

Les sauvegardes et courriels peuvent survivre à la destruction dans l’application jusqu’à leur expiration.
